# hw: Agent Rules

This repo has two parts:
- `playground/`: the Next.js prototype playground (all app code). **Before you do any prototype work, read `playground/AGENTS.md` in full and follow it.** Run all npm commands from `playground/`.
- `docs/`: project notes and references (`docs/playground/references/idea-breakdown.md` is the Road Scroll design brief; `docs/tracks.md` lists the hackathon tracks).
- `docs/design-rules/`: UI/UX design rules. **Before you design or change any screen, read `docs/design-rules/README.md` and the files that apply, and run `09-review-checklist.md` before you deliver.**
