# Layout and spacing

- Group related elements. Space inside a group is smaller than space between groups (proximity shows relationship).
- Use only spacing tokens (8, 16, 24, 32, 48, 80pt). Pick the token by how closely related the elements are: closer relation = smaller token.
- Be generous with white space; crowded layouts are harder to scan.
- Design at 1x in points. Keep line heights divisible by 4 (4pt vertical grid) and sizes on an 8pt grid.
- Align the main layout to a 12-column grid.
- Left-align text. Avoid mixing multiple alignments in one view.
- Create hierarchy with size, weight, contrast, colour saturation and depth (shadows). Test with the squint test: blur your view, the most important items should still stand out.
- Keep related actions close to the content they affect (Fitts's Law). Targets at least 48x48pt.
- Make layouts unbreakable: handle long text, short text, missing images and different screen widths without overlap or truncation of critical content.
- Photos: use the rule of thirds for focal points.
- Align repeated blocks and keep text lengths similar across them so rows look tidy.
