# Typography

- One sans-serif typeface for everything. A second typeface for headings only if it adds needed personality and stays legible.
- Prefer typefaces with a tall x-height and generous letter spacing (better at small sizes).
- Weights: regular and bold only (semi-bold may replace bold if bold is too heavy). Do not use very thin or very thick weights at small sizes.
- Sizes come from a type scale (1.2 Minor Third by default; smaller scale for dense apps/dashboards, larger for marketing). Round to whole pixels. Use a smaller scale on mobile if headings wrap badly.
- Long body text: at least 18px.
- Line height: at least 1.5 for long body text (1.5-2 is good). Reduce line-height ratio as font size grows (headings around 1.2-1.3). Taller lines for long line lengths, heavy or large-looking typefaces.
- Line length: 40-80 characters including spaces.
- Left-align text. Avoid justified and centred paragraphs.
- Reduce letter spacing slightly for large heading text set in text typefaces.
- Never use light grey text; all text at least 4.5:1. Avoid pure black on white.
- Avoid UPPERCASE except short labels: small size, bold, increased letter spacing (about 2px).
