# Forms

- Single-column layout.
- Minimise fields; remove any that are not essential.
- Mark both required and optional fields. Prefer avoiding optional fields via opt-ins that reveal the extra field.
- Field width matches expected input (postcode narrow, address wide).
- Conventional field styles: visible rectangle, label above, not inside the field. Keep the circle on radios and the square/tick on checkboxes even in custom styles.
- Labels always visible; never use placeholder text as the label. Keep labels close to their field.
- Hints go above the field, not below, and must be visible if critical.
- Prefer radio buttons over dropdowns for short lists; autocomplete for long known lists (about 10 suggestions max, bold the differences); steppers for small numeric values.
- Use a checkbox or toggle for two options. Phrase checkbox labels positively.
- Long forms: break into steps (show step count, Back at top left) and group related fields under headings.
- Field borders at least 3:1 contrast.
- Validation: disabling submit until required fields are valid is allowed (see button rules). Show clear inline errors (icon + text + border), explaining how to fix.
