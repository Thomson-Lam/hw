# Navigation and search

Paraphrased from *How to Design Better UI* 3.0 (Kuleszo).

## Navigation bar
- Logo top left and clickable (returns home).
- Link text meets 4.5:1, including on semi-transparent or blurred headers.
- Short, plain link names.
- Make the CTA stand out from regular links (button or divider, stronger contrast or weight).
- Too many links: dropdowns or mega-menu, or move extras to the footer. Plan for the smallest desktop width.
- Hover state on every link; always show the active page.
- Sticky nav is fine; add a slight shadow (raised token) for elevation.
- Mobile tab bar: 3-5 primary destinations, icons plus labels, active item highlighted; key actions in thumb reach, flow-interrupting ones (back, close, delete) out of reach.

## Breadcrumbs and tabs
- Breadcrumbs show location (Home > Category > Subcategory) or clickable steps in a flow.
- Tabs split content into panels on one screen; mark the active tab clearly.

## Search
- Easy to find, near the top; add global search if the product relies on it.
- Show recent searches with clear-all and remove-one controls.
- Autocomplete, about 10 suggestions max.
- Placeholder gives example queries but is never the only label.
- Visible border or fill, 3:1 contrast, at least 48pt tall.
- Match corner radius and stroke to the system; leave whitespace around it.
