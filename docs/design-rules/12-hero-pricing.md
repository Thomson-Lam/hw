# Hero sections and pricing

Paraphrased from *How to Design Better UI* 3.0 (Kuleszo).

## Hero section (above the fold)
Include: value proposition, reason to trust, main benefits, action to take.
- Simple, direct headline; flat, on-brand visuals that support the message.
- One prominent high-contrast primary CTA; optional secondary CTA.
- Social proof nearby.
- Left-aligned by default; centred only for visual-led heroes.
- CTA copy is action- or benefit-led, never "Click here" or "Submit".

## Pricing layout
- One column/card per plan; communicate value, not just price.
- Highlight the recommended plan (larger card, border, tag) and say users can scale later.
- Social proof: logos, reviews, ratings, secure-payment badges.
- Long comparison tables: sticky header with plan names and prices.
- Tooltips for unclear features (hover, focus and tap).
- Low-risk entry (trial, one-time option) when it fits.
- Feature lists: icon plus text for included/excluded, never colour alone.
