# Tables and data

Paraphrased from *UI Pedia* (Pixsel Academy, 2021).

## When to use what
- Table: many similar records to scan, sort or filter. List: short homogeneous items. Cards: varied, browsable content.

## Layout
- Left-align text; right-align quantity/size numbers; align headers with data.
- Row density: condensed 40px, regular 48px, relaxed 56px; toggle outside the table. Controls inside rows still follow the 48pt rule.
- Sticky header; sticky first column on horizontal scroll.
- Smooth scroll on both axes; avoid tall multi-line rows.
- Show total count; clear pagination or show all.
- Resizable columns only for unpredictable data. Column show/hide and freeze via header menu.

## Sorting and filtering
- Minimum: header sort with chevron that does not shift alignment.
- Default sort: most recent or urgent first.
- Search/filter for large sets.

## Row interactions
- Reveal actions on hover, focus and selection; on touch, show a visible row menu (three dots) instead of relying on hover.
- Row details: inline expand, modal, or side panel (most scalable).
- Bulk actions: checkbox per row; show action bar after selection with count.
- Inline editing for low-stakes data; edit in detail view for high-stakes.
- Confirm edits with Save/Cancel, Enter or check icon.
