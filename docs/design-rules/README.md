# Design rules

UI and UX rules for every prototype. Read the files that match the work, and run `09-review-checklist.md` before you deliver any screen.

## Precedence
1. Project decisions: no gradients anywhere; disabled buttons are allowed (`07-buttons.md`).
2. Practical UI rules: files 01-09.
3. Book additions: files 10-18. Where they conflict with 1 or 2, follow 1 and 2 (see the conflict tables in `13-book-additions.md` and `18-uipedia-additions.md`).

These rules cover how things look and read. `playground/AGENTS.md` still covers how to build them (tokens, components, file layout). If the two conflict on a visual or UX point, these rules win.
